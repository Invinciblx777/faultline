# FAULTLINE design system

FAULTLINE's interface is Android 16 / Material 3 Expressive, adapted for the web. One visual language, one token file, one component folder.

- Tokens: [`apps/web/src/design/tokens.css`](../apps/web/src/design/tokens.css), generated by [`apps/web/scripts/gen-tokens.mjs`](../apps/web/scripts/gen-tokens.mjs) (`pnpm --filter @faultline/web tokens:generate`). Do not hand-edit colors.
- Components: [`apps/web/src/design/components/`](../apps/web/src/design/components/)
- Live showcase: `/design` (signed in) renders every component in the dark and light schemes side by side.
- Reference: [`docs/design/reference-android16.png`](design/reference-android16.png), the operator-supplied Android 16 Material 3 Expressive reference this system follows. Android and Material Design are trademarks of Google LLC; FAULTLINE is not affiliated with Google.
- Before/after captures of every migrated screen: [`docs/design/before-after/`](design/before-after/)

## Principles

1. **Evidence is the hero.** Verdicts, counts and screenshots get the biggest type and the expressive shapes. Chrome stays quiet.
2. **Tone, not lines.** Hierarchy comes from the five `surface-container` tiers and from gaps. No dividers, no drop shadows, no hairline borders around cards.
3. **Color is never the only signal.** Every status has its own icon and its own words; inconclusive also changes its edge (dashed).
4. **Warm, never gray.** Surfaces are tinted from the warm neutral seed. No pure black, no neutral gray.
5. **Round, by hierarchy.** Bigger and more important means rounder. Nothing under 8px.
6. **Motion confirms, it never decorates.** Springs on state change; reduced motion gets a 150ms opacity fade on entrances.

Raw hex is allowed only in `tokens.css`. `pnpm lint` runs `lint:tokens`, which fails on any hex color in a `.tsx` file.

## Shape

| Token | Radius | Used for |
|---|---|---|
| `extra-large` | 28px | Bottom sheet top corners, hero cards |
| `large` | 20px | Cards, Blast Radius tiles |
| `medium` | 16px | List-group outer corners, inputs |
| `small` | 8px | Chips, inner list rows |
| `full` | 9999px | Buttons, nav pills, segmented controls, sliders |

Expressive shapes (`ExpressiveShape`): a 12-lobe **scallop** behind the Blast Radius count and a **blob** behind the verification verdict word. Both are decorative SVGs (`aria-hidden`) tinted by status.

Buttons morph on press: `rounded-full` to `rounded-lg` with a 0.97 scale.

## Type

Font: **Manrope** variable, self-hosted via `@fontsource-variable/manrope`. Google Sans Flex is not in the repository, so Manrope substitutes for it: geometric, open apertures, variable weight. Labels get `word-spacing: 0.14em` so all-caps verdicts such as STILL FAILING keep a visible gap.

| Style | Size / line | Weight |
|---|---|---|
| `md-display-large` | 57 / 64 | 700 |
| `md-headline-medium` | 28 / 36 | 600 |
| `md-title-large` | 22 / 28 | 500 |
| `md-title-medium` | 16 / 24 | 500 |
| `md-body-medium` | 14 / 20 | 400 |
| `md-label-medium` | 12 / 16 | 500 |

Numbers use `tabular` (tabular figures). Hashes and SHAs stay monospace.

## Motion

| Token | Spring | CSS approximation |
|---|---|---|
| Default spatial | stiffness 380, damping ratio 0.8 | 350ms `cubic-bezier(0.34, 1.36, 0.64, 1)` |
| Fast spatial | stiffness 700 | 250ms |
| Effects | stiffness 1600 | 150ms `cubic-bezier(0.2, 0, 0, 1)` |

The navigation pill uses the default spring through `motion` (already a dependency). Blast Radius tiles enter staggered 30ms apart, capped at 300ms. Under `prefers-reduced-motion`, entrances become a 150ms opacity fade and every other transition is instant.

## Layout

- Desktop: 80px navigation rail, icon over label, active item in a `secondary-container` pill.
- Mobile (< 768px): bottom navigation bar with the same pill, small top app bar.
- Content column: max 1200px, 24px page padding (16px on phones).
- Hit targets: 48px minimum. Focus: 3px `secondary` ring.

## Components

| Component | Purpose |
|---|---|
| `Card` | Tonal container; `tier` picks the surface-container level |
| `FilledButton`, `TonalButton`, `OutlinedButton`, `TextButton` | Actions, by emphasis |
| `IconButton` | Standard, filled, or destructive (coral) icon action; label required |
| `Chip` | Status: broken, degraded, resilient, inconclusive, failed, neutral |
| `SegmentedControl` | Single choice, e.g. Baseline / Fault on phones |
| `ThickSlider` | 40px track, 4px handle bar with 6px gaps; arrows, PageUp/PageDown, Home/End |
| `SegmentedProgress` | Gapped phases: queued, running, completed |
| `ListGroup`, `ListItem` | Gap-separated pill rows; outer corners round, inner corners small |
| `DialogPanel` | Icon, title, body, "Keep in mind" bullets, full-width filled then outlined actions |
| `BottomSheet` | Slides up on phones, docks right on desktop; Escape and scrim close it |
| `DisplayNumeral` | Hero number in display-large |
| `ExpressiveShape` | Scallop and blob backdrops |
| `NotificationCard` | Icon, source, time, title, body, trailing chevron; used for session, PR and comment rows |

## Do and don't

| Do | Don't |
|---|---|
| Separate list rows with a 2px gap on a tonal row | Draw a divider line between rows |
| Raise importance with a higher `surface-container` tier | Add a drop shadow or a 1px border around a card |
| Pair every status color with its icon and its word | Show a colored dot as the only status signal |
| Take every color from a `--md-sys-color-*` token | Write a hex value in a component |
| Use warm tinted surfaces in dark mode | Use `#000` or a neutral gray background |
| Put the one number that matters in `DisplayNumeral` on an expressive shape | Put an expressive shape behind body text or controls |
